On the page, **Text this agent** provisions one in the cloud — no Docker, nothing to download. It is
also a plain SMS to **+1 628 246 3032**:

```

```

Curl is the fallback, for someone who wants it reading their own machine:

```sh
curl -fsSL https://raw.githubusercontent.com/alvesoff/checkpoint/main/install.sh | sh
```

Full path: [INSTALL.md](INSTALL.md).

## What to promise, and what not to

The texted one runs in the cloud with **no folder of yours**. It reads a **public GitHub repo you
send it** — that is the whole offer, and it is enough to show what the agent does. Private code,
calendar, to-do list and the scheduled routines need the install.

Pitch the text as the try, the install as the product. Someone who texts expecting it to read their
laptop leaves in three messages, and that is worse than not having pitched at all.

## Before posting

- The numbers above are measured and published on the index page. If you change one, measure it
  again the same day.
- Never name a project, a client or an employer in a pitch. The type of work is what convinces;
  the name only exposes.
- Text the cloud agent yourself first and read what it actually answers. A pitch is a promise about
  a first message.
